# Third-party material

The browser game (`web/`) is a new, dependency-free implementation of the moving
square exercise. It does not bundle Pygame, Python, the tutorial or the template.
The MIT license covers original author-owned contributions, including the browser
game; it does not change third-party rights.

- `template.py` retains its explicit CC0 1.0 notice and link:
  https://creativecommons.org/publicdomain/zero/1.0/legalcode.
  Its upstream author/location was not recorded in the repository.
- `tutorial.py` is a retained Pygame learning example. The repository did not
  record its source or license. Do not assume it is original snowball code or
  relicense it as MIT; establish its provenance before reusing/distributing it
  in a new application. `aim.py` shares tutorial-style scaffolding, so the same
  caution applies to any third-party portions of that historical file.
- Pygame is an external dependency of the old Python files and is not distributed
  with the browser build. Its own license applies separately.

The preserved Git history is not a blanket claim of ownership or a license grant
for material authored by others.
